# 🚗 Road Accident Severity Prediction

## 📌 Project Overview
This project focuses on predicting road accident severity using Machine Learning techniques. It analyzes road accident data to classify accidents based on their severity.

## 📊 Dataset Information
- Dataset Name: Road.csv
- Total Records: 12,316
- Total Features: 32
- Target Variable: Accident_severity

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn

## 🤖 Machine Learning Algorithm
- Balanced Random Forest Classifier

## ⚙️ Project Workflow
1. Data Collection
2. Data Preprocessing
3. Data Cleaning
4. Handling Missing Values
5. Feature Encoding
6. Model Training
7. Model Testing
8. Model Evaluation
9. Data Visualization

## 📈 Model Evaluation
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## ▶️ How to Run
1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn
```

3. Keep `Road.csv` and the Jupyter Notebook in the same folder.
4. Open the notebook in Jupyter.
5. Run all cells.
